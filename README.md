# CO-PO Mapping & Attainment Tool

**NAAC-Ready · Free for All Faculty · Open Educational Resource**

A unified, browser-based tool for faculty to create CO-PO Mapping matrices,
calculate CO & PO Attainment, and generate printable NAAC-ready reports.

## Features
- CO-PO Mapping (Yes/No) for 3-6 COs x 12 POs
- CO Attainment: Threshold (60/60) + Average Marks methods side by side
- PO Attainment auto-calculated from mapping x CO levels
- Attainment levels 0/1/2/3 with color badges
- Bar charts for CO and PO attainment
- Print as PDF, Download CSV, Copy to clipboard
- Course info entered once, shared across both modules
